# 🎮 Rock Paper Scissors Game

An interactive **Rock Paper Scissors game** built using **HTML, CSS, and JavaScript**.  
In this game, the player competes against the computer. The computer randomly selects its move and the result is displayed instantly along with the updated score.

This project demonstrates the use of **JavaScript DOM manipulation, event handling, and simple game logic**.

## 🎮 How to Play

1. Choose **Rock**, **Paper**, or **Scissors**.
2. The computer will randomly choose its move.
3. The result will be displayed instantly.
4. Scores will update automatically.
5. Continue playing and track the history in the leaderboard.
